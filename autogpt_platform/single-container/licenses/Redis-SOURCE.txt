image copies /usr/local/bin/redis-server from the pinned FalkorDB container
image to /opt/falkordb/redis-server. Redis 8.6.3 is offered under its
upstream tri-license. The complete upstream license bundle and contributions
notice are provided beside this file. The license and copyright notices for
the dependencies linked into the upstream Redis server are preserved under
deps/ and src/ using component-corresponding paths. Redis embeds fast_float's
MIT notice in its vendored header, so the standalone LICENSE-MIT here comes
from the matching upstream fast_float v6.1.4 tag. The official Redis image
packaging modifies the default protected-mode setting and jemalloc build
configuration; the exact packaging source above records those changes.

Redis license path and whole-image notice bundle.
