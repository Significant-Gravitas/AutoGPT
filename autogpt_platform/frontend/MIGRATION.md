# Migration to Kobra

Started 2026-10-08 on branch `ds/kobra-migration`. Old system: the house
atoms, molecules and organisms in `src/components`, built on Radix
primitives (`@radix-ui/*`), `sonner`, `cmdk`, `vaul`, `react-day-picker`,
`embla-carousel-react` and the shadcn files in `src/components/ui` and
`src/components/__legacy__/ui`.

Kobra is built on Base UI (`@base-ui/react`). The registry needs a paid token
(`KOBRA_TOKEN`), which this environment does not have, so each component was
pulled through the Kobra MCP (`get_component`) and written verbatim to
`src/components/ui/<slug>.tsx` with its stylesheet beside it as
`<slug>.css`. The registry block is in `components.json`; with a token,
`npx shadcn@latest add @kobra/<slug>` writes to the same place and is the
way to update a component.

## Foundations

- **Registry**: `@kobra` namespace in `components.json`; `aliases.ui` now
  points at `src/components/ui` (the git-ignored `__shadcn_scratch__`
  directory and its lint rule are gone).
- **Tokens**: the house semantic tokens in `src/app/globals.css` already use
  shadcn's names (`--background`, `--primary`, `--muted`, `--border`,
  `--ring`, `--radius`...), which are the tokens Kobra reads. They are kept
  as the contract; Kobra's own `:root` values for tokens the house already
  defines (`--success`, `--warning`, `--info`) are not copied. New tokens
  Kobra introduces (`--error`, `--push-*`, `--ring-duration`,
  `--shell-fg-*`, `--toast-morph-*`) are added beside them.
- **Radius**: `--radius: 0.75rem` kept. Buttons stay pills (`rounded`
  variant on Kobra's Button) so no screen shifts shape.
- **Dark mode**: already a `.dark` class on the root. Nothing to bridge.
- **Fonts**: Geist and Poppins kept. Kobra reads `--font-sans`.
- **Icons**: Kobra files keep their Lucide glyphs (chevrons, checks, marks);
  the atoms keep Hugeicons through the `Icon` atom. `src/components/ui/` is
  exempt from the Hugeicons-only lint rule and from the Tailwind class rules
  (it is registry output and is not edited by hand).
- **Motion**: `framer-motion` replaced by `motion` (same API, `motion/react`),
  which Kobra's Toast uses.
- **Sound layer**: `src/components/ui/sound.tsx`, wrapped once in
  `src/app/providers.tsx` through `layout/SoundLayer`. Kobra's `data-slot` attributes drive it. Muted
  state is per-browser in `localStorage`; `SoundToggle` exposes the switch.
- **Lint**: `src/components/ui/*` may only be imported from inside
  `src/components` (rule unchanged). The atoms and molecules remain the
  house API; their implementation moves onto Kobra.

## Decisions

- The atom and molecule layer stays. Every importer of
  `@/components/atoms/Button/Button` and friends keeps working; the atom
  renders the Kobra component and maps the house props onto it. The compat
  layer the method describes is therefore the atoms folder itself, and it is
  permanent, because the lint rules already make it the only public surface.
- Dead components deleted (zero importers): `atoms/ToggleChip`,
  `atoms/LLMItem`, `organisms/BriefingCard`, `organisms/NeedsAttentionList`.
- The AI chat components (`ai-elements/*`) and decorative one-offs
  (`ui/aurora-background`, `vortex`, `dot-distortion-shader`,
  `text-generate-effect`) are out of scope for this pass. Kobra's
  Conversation, Message and Chat Input are additions to evaluate after the
  migration, not replacements during it.

## Known behaviour changes

- Menus (DropdownMenu, SecondaryMenu, Select) open on mousedown/click; tests that fired `pointerDown` were moved to `click`.
- Skeleton no longer uses `animate-pulse`; select it by `[data-slot=skeleton]`.
- Tabs expose `data-active`, disclosure parts expose `data-open`, instead of Radix's `data-state`.
- Toast default lifetimes follow Kobra (2.4s, 4s with description, 6s with action) unless `duration` is passed.
- Sound: every Kobra control answers a press. Muted per browser via `SoundToggle` / `setSoundMuted`.
