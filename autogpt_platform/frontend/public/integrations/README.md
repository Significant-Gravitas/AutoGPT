# Integration logo sources

These logos identify their respective services. The files below are unmodified PNG assets from the services' official websites or brand repositories.

The generic `database.png` and `generic_webhook.png` icons are rendered from `Database02Icon` and `WebhookIcon` in the project's `@hugeicons/core-free-icons` 4.2.3 package (MIT), at 128 pixels with a 2px stroke and zinc-700 color. They identify connection types rather than external brands.
