# Category contrast revision

Eighteen transparent 512px PNG edits made with the built-in Codex image-generation tool. `PROMPTS.json` records each source image, category shade, and full edit prompt.

Marketing uses deep terracotta (#C45F36), Sales uses gold (#D5AB24), and Support uses rose (#C45B88), with lighter and darker shades for each expert. This user-approved change makes the three categories easier to tell apart while keeping the same shapes, faces, and cream accents. The shared avatar catalog supplies these colors to bodies, backgrounds, filter dots, and the live creator. Otto retains reserved lavender.

Generated images keep true alpha transparency. Outputs were resized to 512px with `sips`; no programmatic recoloring was used. Earlier versioned artwork remains available for saved URLs.
