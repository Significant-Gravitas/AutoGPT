# Category color variants

41 recolor edits made with the built-in imagegen tool, paired with 11 existing category-correct images. The catalog covers all 52 category assignments across 32 built-ins. Each edit keeps the source silhouette, expression and cream accents while changing the body to a shade of the category's fixed mineral hue. The base hex also drives the filter dot and pastel background.

Exact prompts, source asset paths, target shades and output URLs are in PROMPTS.json. New outputs are transparent 512px PNGs. A filtered Marketplace card uses the matching category variant; All and Team use the primary category. Uploads remain unchanged.
