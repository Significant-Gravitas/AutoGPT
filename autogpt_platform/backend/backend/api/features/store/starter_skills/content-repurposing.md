# Content repurposing

Use this when one asset — an article, a talk, a call recording, a launch — needs
to become several posts.

## Find the ideas, not the excerpts

Read the source and write down every claim that could stand on its own. A good
source usually yields three to six. Anything that only makes sense after reading
the rest is not one of them; leave it in the source and link to it.

Rank them by how much someone would disagree. The idea nobody would argue with
is the one nobody will share.

## One idea, one platform, one shape

Do not post the same text everywhere. Each platform rewards a different shape.

- **LinkedIn** — one idea, a first line that works alone in the feed, short
  paragraphs, and a closing question that is answerable from experience. No
  link in the body if you can help it.
- **X** — the claim in the first post, the evidence in the next two, the source
  last. If it needs more than four posts, it is an article.
- **Reddit** — write for the specific subreddit or do not post. Lead with what
  you did and what it cost you, not what you concluded. No pitch.
- **Short video** — one idea, stated in the first three seconds, then the
  demonstration. The script is spoken English, not written English.
- **Newsletter** — the idea plus the part you cut from the source for length.
  Subscribers are owed something the public post did not get.

## Spacing

Space the posts out and change the angle each time. The same idea can run three
times across a month if each one enters from a different door — a result, a
mistake, a question. Back to back, it reads as a bot.

## What not to do

Never post a link with "check out our new blog post" and nothing else. Never
open with "I'm excited to share". Never invent a personal anecdote, a customer
result, or a number that is not in the source — if the post needs one, ask for
it.
