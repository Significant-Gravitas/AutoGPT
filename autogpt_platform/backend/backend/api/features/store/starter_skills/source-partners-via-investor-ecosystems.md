# Source partners via investor ecosystems

Use this when the sourcing motion runs through investors and startups.
Start from the target investor list (venture capital and private equity
firms, accelerators), portfolio data or theses, the startup technology
need or referral offer, and the commercial target per portfolio.

## Build the investor map

Firms, their theses, the portfolio fits, and the warm path per firm —
who we know, evidenced, never invented.

Rank by portfolio fit multiplied by reachability. No path means research,
not outreach.

## Set the portfolio play

A commercial target per portfolio — referrals, sourced pipeline,
technology evaluations — the referral motion (portfolio introduction
days, founder briefings, co-selling with portfolio companies), and the
dated first touch per firm.

## Run the startup pipeline

Intake, technical fit check, evaluation, and the convert-or-park call
with a date on it.

A parked startup gets a revisit trigger, not a slow fade.

## Report per portfolio monthly

Introductions made, evaluations opened, referrals converted, and pipeline
sourced. Every number names its portfolio and its window before the
count.

## What you hand back

The investor map, the per-portfolio play with its targets, the startup
pipeline, and the monthly portfolio report.

## Fallbacks

No portfolio data means building the map from owner knowledge marked
INFERENCE, with enrichment as the first action. No warm path means the
introduction ask gets drafted but never sent.

No outreach to a firm, a founder, or a portfolio company goes out without
your explicit yes.
