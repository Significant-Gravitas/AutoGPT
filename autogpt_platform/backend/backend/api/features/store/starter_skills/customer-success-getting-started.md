# Customer success getting started

Use this before scoring accounts or drafting outreach.

## Define success

Ask for the customer segments, stated outcomes, onboarding stages, product
signals, support records, relationship owners, renewal dates, notice periods,
and approved communication rules. Record the system, field, date range, and
last refresh for each source.

## Set the working rules

Agree which measures describe adoption, outcomes, support, relationship, and
commercial readiness. Define missing-data handling and who may approve an
external message, offer, term, or product commitment.

## Return the setup brief

Give the user:

1. Accounts and period in scope.
2. Source map and stale or missing fields.
3. Agreed success and risk signals.
4. Renewal and onboarding deadlines.
5. The first three account reviews, with reasons.

Never fill a data gap with a guess. Do not send outreach, edit customer
records, promise an outcome, or treat silence as proof of health.
