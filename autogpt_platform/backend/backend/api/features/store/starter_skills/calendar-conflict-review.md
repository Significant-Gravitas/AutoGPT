# Calendar conflict review

Use this for a day, a week, or the run-up to a trip.

## Scan the period

State the period and which calendars you could read. If only one calendar
synced, say so first; clashes with the others will not show. Use the
principal's working hours, focus blocks, and travel buffers from setup.

## List the problems

For each day list:

- clashes, with both events and their organisers;
- back-to-back meetings in different places with no travel time;
- days over the agreed meeting load, or with no focus time left;
- events outside working hours;
- tentative holds that are about to lapse.

Rank the problems by what they put at risk, using the stated priorities.

## Options to approve

For each problem give one to three options: move, shorten, delegate, decline,
or keep. Say who each option affects and draft any message it needs. Present
them as a list the principal can answer with a letter or a yes.

Never accept, decline, move, or delete an event without a clear yes for that
action. Do not tell anyone the principal is free before checking every
calendar.
