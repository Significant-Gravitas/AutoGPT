# Candidate interview debrief

Use only submitted scorecards tied to the approved rubric. Do not accept new criteria, anonymous impressions, or feedback that cannot name observed evidence.

## Assemble before discussion

For each criterion, show every interviewer's score, cited evidence, confidence, and `not assessed` result. Calculate no hidden overall score. Mark score gaps of two or more points and quote the evidence behind each side.

Sort notes into:

- confirmed job-related evidence;
- conflicting evidence to resolve;
- missing evidence;
- out-of-rubric or disallowed feedback to exclude.

Remove protected-trait data and proxies from the decision record. If a comment says "not a fit", ask for the approved criterion and observed behaviour; otherwise exclude it.

## Run the handoff

Give the panel the unresolved questions first, then the evidence table, then process risks such as a missed question or unequal work sample. Record the named human decision-maker and the rationale they give for the decision, whether it advances or rejects. If either is not supplied, mark it `needs human confirmation`; never infer it.

## Output

Return the evidence summary and open questions. Never recommend or make the advance, reject, hire, offer, or pay decision.
