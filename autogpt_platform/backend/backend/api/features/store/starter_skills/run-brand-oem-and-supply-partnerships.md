# Run brand, OEM, and supply partnerships

Use this when the portfolio is not a resale motion. Start from the
portfolio itself — properties, original equipment manufacturer (OEM)
product lines, agents, and application or supply-side partners — the
current spend and attach numbers, the contracts and budgets, and the
portfolio owner.

## Run sponsorships as a portfolio

Properties, activation plans, budgets, and the measured outcome per
activation.

Every renewal pairs its spend with its evidence. Spend with no outcome
behind it gets flagged, never auto-renewed.

## Run OEM sell-through

Attach rates per product line, pipeline per OEM, enablement for each
OEM's seller team, and the quarterly OEM read.

A stalled OEM gets one dated activation window before the invest call
changes.

## Run agent and supply ecosystems

The agent or supply-partner roster, the referral or attach motion per
partner, and the monthly throughput read.

A coverage gap gets a named recruit-or-drop call, not an open question.

## Read the portfolio quarterly

Spend against return per line, the winners to feed, the losers to exit,
and the reallocation draft.

Reallocation is staged with its evidence. The owner makes the call.

## What you hand back

The sponsorship read, the OEM sell-through read, the agent and supply
read, and the quarterly reallocation draft.

## Fallbacks

No attach data means running from owner-stated numbers marked INFERENCE,
with feed setup as the first action. No contracts on file means flagging
Legal review before any renewal.

No spend, renewal, or reallocation goes out without your explicit yes.
