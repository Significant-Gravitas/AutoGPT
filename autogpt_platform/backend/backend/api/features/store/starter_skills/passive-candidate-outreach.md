# Passive candidate outreach

Run this when the user picks someone to contact, asks for a first message or a
follow-up, or wants outreach written for a whole batch.

## Inputs

The candidate card, the role scorecard, who the message comes from, and the
channel.

## One message per person

Never a template with the name swapped in.

## Shape

Four to six sentences, under 60 words. The subject line names the specific
trigger, never "quick question". Open with the specific thing you found and
where you found it. One line on the role and why this person in particular.
One line on what they would actually care about: the problem, the scope, the
team, or the stage. One clear ask, as a question, on its own line.

Say where you found them. It is the most credible line in the message and it
is the honest thing to do.

## Facts only from the card

Never invent a mutual connection, never claim you read something you did not,
and never write "I came across your profile" when you can name the talk, the
repository, or the writeup. No hype: no "exciting opportunity", no "rockstar",
no flattery the user would not say out loud. Match how the user writes when
you have seen their writing.

Pay, title, and start date only when the user gave them to you. Never estimate
a band.

## Sequence three touches

Day-2 bump, day-5 new angle with a fresh proof point, day-8 close-out. Every
touch adds new value, never "just bumping this". Keep the ask low friction
each time — a reply, not a booked call — and no calendar link in a cold note.
Send the first note Tuesday morning in the candidate's timezone when you know
it, and vary the day and time of each follow-up. Stop after three touches
unless the user says otherwise, and record a no the first time you hear it.

## Output

The draft in chat, ready to copy. With Gmail connected, leave it as an unsent
draft and say it is sitting there. Log the draft against the candidate with
the date and the channel, so the weekly review can tell who is waiting on a
reply.

## Fallbacks

With a thin card, write the shorter honest version and name the one fact that
would make it stronger instead of padding it. With no sample of the sender's
voice, write plain and warm.

## Approval gate

Never send, message, or post without an explicit yes for that specific
message. A do-not-contact flag ends it: no draft, no batch, no exceptions.
