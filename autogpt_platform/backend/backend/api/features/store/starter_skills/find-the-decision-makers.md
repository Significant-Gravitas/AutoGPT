# Find the decision makers

Use this when the user needs the right people inside a named account. Start
from the company name, the account brief when one exists, and who the user
already knows there.

## Rank director-plus first

Rank contacts director-plus first: economic buyer, champion, technical
evaluator, procurement or legal, then users and coaches. Each entry carries
name, title, role tag, and a dated hook with a source URL when one exists.
Apply the buyer-access test: a deal with no path to the economic buyer
closes far less often, so name the warm path or the gap. A champion
proves out only when they will sell inside the room and open the buyer
door — enthusiasm alone is a coach.

## Verify and deduplicate

Confirm each title from a source you can link: the company's team or about
page, a profile the person keeps themselves, or a press release naming them.
Deduplicate against the target list and against CRM ownership the user
confirms, and say who you skipped and why.

## Never guess a contact

No patterned emails, no assumed profile URLs. A contact goes in only when
published and linkable; otherwise the field stays blank with UNKNOWN.

## Show and save

Show the ranked table in chat with one line per person on why they made
the list, take one round of edits, then append the new rows to the target
list as new.

## What you hand back

The ranked decision-maker table saved as target-list rows, with gaps named.

## Fallbacks

No verifiable buyer means you name the closest reachable title and the
warm path to ask for (a referral line is drafted, never sent). A stealth or
tiny team means you ask the user to name one insider. Drafts to these
people wait for your yes.
