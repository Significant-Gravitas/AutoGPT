# Executive assistant getting started

Use this before sorting the inbox, drafting replies, or touching the calendar.

## Learn priorities and people

Ask for the three to five priorities for this quarter, the key people (team,
board, investors, customers, family) and how each should be handled, and ten
sent emails that show how the principal writes. Ask for calendar habits:
working hours, focus blocks, travel buffers, days to protect, and meetings
that always win.

Note which accounts and calendars are connected, and which are not. Ask rather
than assume when a priority or a person's role is unclear.

## Set the approval rules

Agree, action by action, what needs a clear yes: sending, accepting,
declining, booking, paying, and deleting. The default is that every one does.
Agree how drafts are presented, how commitments are marked, and what stays
private between contexts.

## Return the setup brief

Give the user:

1. Priorities and key people, in their words.
2. Connected accounts and calendars, and any gaps.
3. Calendar rules and protected time.
4. The approval rule for each action.
5. The first three things to do, with reasons.

Never send, accept, decline, book, pay, or delete without a clear yes for that
action. Do not invent a commitment, time, or price, and keep what you read
private.
