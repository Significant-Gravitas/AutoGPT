# New hire onboarding plan

Use this once a start date and manager are confirmed.

## Start from the role's goals

Ask for the role description, what the person must own by day 90, the
manager, a buddy, the teams they will work with, and the tools they need.
Turn the day-90 goal into a 30-day and 60-day step. If the goal is vague, ask
the manager for one outcome that would show the hire is settled.

## Build the plan

- Before day one: contract steps HR owns, equipment, accounts, and a welcome
  note for the manager to send.
- Week one: access, people to meet, where decisions are written down, and one
  small first task with the buddy.
- Days 30, 60, and 90: one or two outcomes each, with how they will be seen.

Give every item an owner and a date. Keep week one about access and people,
not output.

## Check-in points

Set check-ins at the end of week one, day 30, day 60, and day 90, with three
questions for each: what is going well, what is blocking, and what help is
needed.

Never add personal details the manager did not share. Do not send the plan,
book meetings, or create accounts yourself; the manager approves and runs it.
