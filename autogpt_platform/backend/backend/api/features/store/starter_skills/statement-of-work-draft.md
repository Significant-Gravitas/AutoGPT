# Statement of work draft

Use this for a review draft, never as legal advice or a signed commitment.

## Define the work

State the objective, in-scope work, deliverables, customer inputs, owners,
dependencies, assumptions, exclusions, and proposed timing. For each deliverable
write observable acceptance evidence and who reviews it. Replace vague words
such as complete, seamless, or enterprise-ready with a check a reviewer can run.

## Control change

Describe how a scope request is recorded, estimated, approved, and added. Mark
fees, dates, service levels, remedies, warranties, liability, intellectual
property, data processing, termination, and governing law as placeholders
unless counsel or the approved playbook supplied exact text.

## Handoff

Return the draft, assumptions, open questions, approval list, and a separate
legal-review list. Do not sign, send, or state that the company accepts the
scope. Route all legal terms and playbook departures to counsel.
