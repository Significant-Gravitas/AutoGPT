Small media fixtures for upload signature regressions.

The still and animated AVIF files were generated with Pillow. The MOV, M4V, 3GP, M4A and Matroska files were generated with ffmpeg. `header.heic` is a synthetic ISO-BMFF header with HEIC/mif1 brands, not a decodable image. These test rejection at the upload boundary; they do not test decoding.
