Workspace(title: string, description: string, children: (Prose | Artifact | SeriesChart | Metrics | DataTable | Insight | Checklist | Form | FollowUp | Map | Timeline)[], viewId?: string) — The root workspace. Give it a concise title, summary, and up to eight useful sections. New views require a stable viewId as the fourth argument FROM THE FIRST RENDER; reuse it for revisions of the same view and use a new id for a different task. Omission is accepted only when reading historical views.
Prose(markdown: string) — A block of Markdown text: headings, paragraphs, lists, links, tables and code. Use it for notes, explanations and write-ups that read better as text than as cards. At most 8000 characters; split longer text across several Prose sections. No raw HTML.
Metrics(items: Metric[]) — A responsive row of two to four metrics.
Metric(label: string, value: string, detail: string, tone: "neutral" | "positive" | "warning") — A single KPI with a label, formatted value, supporting detail, and tone.
SeriesChart(title: string, description: string, unit: string, kind: "line" | "bar" | "stacked", series: {key: string, label: string}[], points: {label: string, values: Record<string, number>}[]) — Line, bar or stacked chart for one or more series, with legend toggles, an accessible data table, and true null gaps. Use it for any chart, including a single series. kind is line/bar/stacked. All series use the same stated unit; stacked requires nonnegative values. Points preserve supplied order; each contains label and values keyed by series key, with null for a missing observation. Never connect across a missing period by dropping its point. Up to five series and 100 points.
DataTable(title: string, columns: string[], rows: string[][]) — A searchable, sortable table with at most six columns and 30 rows. Each row must have one string per column. Split larger datasets across tables without dropping rows.
Checklist(title: string, items: {title: string, detail: string, done?: boolean}[]) — An interactive checklist with at most 12 items that the user can tick off locally. Set an item's optional done flag to true for completion the user has reported. Split longer lists into multiple checklists without dropping tasks. This does not execute tasks.
Timeline(title: string, items: {time: string, title: string, detail: string, status: "done" | "current" | "planned"}[]) — A chronological itinerary, milestone plan, or event history with at most 20 items. Preserve supplied dates and time zones; label proposed times as a plan.
Map(title: string, description: string, locations: {name: string, latitude: number, longitude: number, detail: string, category: string}[]) — An interactive geographic map with one to 50 numbered markers, searchable places, details, zoom, and a button to discuss the selected place in this chat. Supply verified latitude/longitude from the user or tools; never guess coordinates. This does not geocode, calculate routes, or request the user's location.
Artifact(title: string, uri: string, mimeType: string, filename: string, description: string) — An inline card for an actual generated or uploaded artifact. Reuses native image/video/audio renderers and file downloads. uri must be the exact tool-returned workspace://file-id#mime/type or HTTP(S) URL, not invented. Provide filename, accurate mimeType, description (also image alt text). No script or HTML execution. For multiple generated images use multiple cards; for choosing images use ResultList with real image URLs. Do not claim an image was generated until the generation tool returned it.
Insight(title: string, body: string, tone: "neutral" | "positive" | "warning") — A short takeaway, recommendation, or caveat. Use warning for missing data.
Form(name: string, title: string, fields: (Field | TextAreaField | SelectField | MultiSelectField | NumberField | DateField | ToggleField | ResultList | Comparison | Itinerary)[], submitLabel: string, message: string) — Collect a brief with at most six fields. Submitting sends the edited values to the assistant; no external action is executed.
FollowUp(label: string, message: string) — A follow-up button that asks the assistant to update the workspace. Never imply an external task was performed.

Use Itinerary for trips with known dates/locations/transfers; use Checklist or Timeline for non-geographic plans. Missing facts require research or clarification, never guess.
Comparison(name: string, label: string, value: string, options: {id: string, title: string, description: string, facts: {label: string, value: string}[], amount?: number, image?: {url: string, alt: string}, source?: {url: string, label: string}}[]) — Two selectable comparison cards inside Form. On mobile, swipe left chooses the first option and right the second; buttons and undo also work. Selection stays local until Form submission. value is an option id, or empty for no choice. Facts, images and source links must be supplied or verified. Preserve the scope of EACH option's supplied facts: a generic warranty duration cannot go under a part-specific coverage label, and labels need not match across cards. ResultList(name: string, label: string, options: {id: string, title: string, description: string, facts: {label: string, value: string, source?: {label: string, url: string}}[], image?: {url: string, alt: string}, source?: {label: string, url: string}, amount?: number}[], value: string[], selection: "single" | "multiple", required: boolean, unit: string) — Rich searchable option cards inside Form for 1–100 options, with fact-level sources and optional verified images {url,alt}; url may be the actual workspace file URI or HTTP(S) image output URL. Single or multiple selection submits stable ids at name; empty means undecided. Publishes name_amount (sum only when every selected amount is known, otherwise null) and name_count. unit explains amounts, e.g. USD/night; keep all amounts comparable. Preserve every candidate. Use Comparison for the user's two-option A/B swipe. This does not execute or approve actions.
Field(name: string, label: string, value: string, placeholder: string, required?: boolean) — An editable, labeled text field inside a Form. Use a unique name.

ToggleField(name: string, label: string, value: boolean) — A labeled true/false checkbox inside Form. Use for a preference or constraint, never as consent to execute an external action.
