## 一次对话，汇聚顶尖专业能力

告诉 Otto 你的待办目标。它会自动调遣最合适的专家团队、无缝分派任务，并实时向你汇报最新进展。当你想要深入探究具体细节时，也可以直接与某位专家单独交流。

每位专家都拥有专属的角色定位，你可以通过个性化指令、上下文知识库、技能拓展以及绑定的应用程序对其进行深度定制。你可以直接使用现成的专家，也可以从零创建属于你自己的专家。

## 从初步需求到自动化例行公事

1. **挑选你的专家**：告诉 Otto 你的需求，选择一位现成专家，或按照你的工作习惯创建专属专家。
2. **下达任务简报**：提供上下文背景信息，连接所需的应用程序，并就首期交付目标达成一致。
3. **审核与微调**：检查交付的工作成果并调整指导规则。为频繁出现的周期性任务激活自动化例行公事（Routines）。

你可以自主选择每位专家能够访问的账号权限、设置支出配额控制，并在活动动态中全程追踪执行进度。

### 私有化自托管 (Self-host AutoGPT)

在自有基础设施上运行 AutoGPT。由你自行提供模型 API 凭证、配置部署环境，并负责日常更新与运维。

自托管的最快方式是使用 Docker Hub 上的单容器镜像 [`significantgravitas/autogpt`](https://hub.docker.com/r/significantgravitas/autogpt)：

```bash
docker run -d \
  --name autogpt \
  --restart unless-stopped \
  --shm-size 2g \
  --ulimit nofile=65536:65536 \
  --log-driver json-file \
  --log-opt max-size=50m \
  --log-opt max-file=5 \
  -p 127.0.0.1:3000:3000 \
  -e AUTOGPT_PUBLIC_URL=http://localhost:3000 \
  -v autogpt-data:/data \
  significantgravitas/autogpt:latest
```

首次启动请等待数分钟，随后访问 [http://localhost:3000](http://localhost:3000) 创建您的账号，并将其设置为系统管理员：

```bash
docker exec autogpt autogpt-admin promote you@example.com
```

关于系统要求、关闭公开注册、端口映射、模型提供商配置、数据备份与版本升级等详细说明，请参阅部署指南：

[阅读单容器部署指南 →](https://agpt.co/docs/platform/self-hosting/single-container)

在 Linux、macOS 和 Windows 上，[一键安装程序 (Installer)](https://agpt.co/docs/platform/self-hosting/installer#install) 可通过单条命令完成相同镜像的环境配置。

如需使用 Docker Compose 让每个服务运行在独立容器中，或希望基于源码进行二次开发，请参阅[手动自托管部署指南](https://agpt.co/docs/platform/self-hosting/getting-started#manual-setup)。

| | 托管云平台 | 私有化自托管 |
| --- | --- | --- |
| **部署与运维** | 由 AutoGPT 官方全托管 | 由使用者自行管理 |
| **模型接入** | 平台内置提供 | 自行提供模型 API 凭证或本地大模型 |
| **费用成本** | 付费套餐与实际用量计费 | 自备基础设施与模型使用成本 |
| **数据与基础设施** | 托管于 AutoGPT 云端 | 完全运行在自有物理/云端基础设施中 |
