## 1. Character

Light, quiet, product-first. Near-white surfaces, zinc neutrals, black text, one violet
accent used sparingly for selection and emphasis. Pill buttons, softly rounded cards,
borders instead of shadows, generous whitespace. Poppins for headings, Geist for
everything else. Grain, glass, and shader backdrops exist for hero and onboarding
moments only, never for everyday screens.

Mood in one line: a calm, well-lit workspace. Not playful, not brutalist, not dark.

## 4. Spacing, radius, elevation

Spacing is a 4px scale (`1` = 4px) with the Tailwind steps plus `4.5`, `7.5`, `8.5`,
`18`, `68`, `70`, `71`, `76`. Common rhythm: `gap-2` inside controls, `gap-4` between
controls, `p-4` to `p-6` inside cards, `gap-6` to `gap-8` between sections, page
padding `px-6 md:px-8`.

Radius names (use these, not raw Tailwind sizes, except where noted):

| Name | px | Use |
|---|---|---|
| `rounded-xsmall` | 4 | tags, tiny chips |
| `rounded-small` / `rounded-md` | 8 / 6 | badges, toggle buttons, inputs |
| `rounded-medium` | 12 | inputs, menus, popovers |
| `rounded-large` / `rounded-2xl` | 16 | cards (`agpt-card`), dialogs |
| `rounded-xlarge` | 20 | panels |
| `rounded-2xlarge` / `rounded-3xl` | 24 | boxes (`agpt-box`), hero panels |
| `rounded-full` | pill | all standard buttons, avatars |

Elevation, lowest to highest:

1. Flat on the page background.
2. `border border-zinc-200 bg-white` (default card).
3. `shadow-subtle` (0 1px 2px rgba(0,0,0,.05)) for inputs and secondary buttons.
4. `smooth-shadow-ring-sm` (six-layer soft shadow plus 1px ring at 5% black) for floating
   cards and popovers.
5. `shadow-md` only inside the `Card` atom.

Prefer borders over shadows. Never stack a shadow on a bordered card.

## 6. Icons and imagery

Hugeicons only, always through the `Icon` atom (`@hugeicons/core-free-icons`),
stroke width 2. Sizes: 14 in xs buttons, 16 in small and icon buttons, 18 in large
buttons, 20 to 24 in headers and empty states. No Lucide, no Radix icons in new code.
Avatars come from `Avatar`, `ExpertAvatar`, `AutopilotAvatar`, `WorkflowAvatar`,
`IntegrationLogo`. Illustrations are rare; empty states use an icon plus text.

## 7. Motion

Framer Motion for enter and exit, `tailwindcss-animate` for primitives. Durations
150 to 250ms, ease-out. Respect `prefers-reduced-motion` (see `ToggleChip`). Height
changes fade (`collapsible-down/up`). No bounce, no parallax, no autoplay loops.

## 9. Patterns

| Pattern | Build it with |
|---|---|
| Page header | `InsetHeaderTitle` + `InsetHeaderActions`, primary action on the right |
| Empty state | centred column: icon 24px zinc-400, `Text h5`, `Text body` muted, one primary or secondary button |
| Loading | `Skeleton` shaped like the final content, never a lone spinner for page loads |
| Error | `ErrorCard` with retry |
| Confirm | `Dialog` with title, one sentence, secondary cancel left, primary or destructive right |
| Form | `Form` molecule, `Input`/`Select` stacked with `gap-4`, actions right-aligned |
| List | `InfiniteList` of bordered rows or cards, `gap-3` |
| Multi-step flow | one artboard per step side by side in Paper; one component per step in code with a small stepper header |
| Status | `Badge` or `RunStatusBadge`, never coloured text alone |

## 10. Do and don't

Do: reuse the inventory, stack with flex and gap, use the type scale, keep one
primary action per view, write real copy, design empty, loading, and error states,
check at 1440 and 390.

Don't: absolute positioning, new colours, off-scale sizes, gradients or drop shadows
on controls, more than one accent moment, icon sets other than Hugeicons, placeholder
lorem ipsum, dark mode (not supported yet), text under 12px, cards inside cards.
