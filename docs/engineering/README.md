# Engineering notes

Notes for the people and agents who work on AutoGPT: architecture, internal references, analytics and tracking plans, rollout plans, runbooks and maintainer guides.

Nothing in this folder is published. The docs site at agpt.co/docs is built from `docs/home/`, `docs/platform/` and `docs/integrations/`, and shows the pages listed in each folder's `SUMMARY.md`. A page written for people using or self-hosting AutoGPT goes there. Everything else goes here.

- Don't list a file from this folder in a `SUMMARY.md`.
- To link to a note from a published page, use its full GitHub URL. The relative path does not exist on the docs site.
